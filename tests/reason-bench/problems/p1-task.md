# P1 — Feature planning: offline editing for a collaborative document editor

You are the product-minded tech lead for a collaborative document editor
(web + iOS/Android). Today the product is online-only: documents are
server-authoritative, loaded/saved over REST, with live multi-user co-editing
over WebSocket — several users routinely edit the same document at once.
Product leadership wants: "Users can keep editing without a connection, and
everything syncs when they're back online."

Write the feature plan you would actually hand to the team:

- Scope and explicit out-of-scope
- Phased milestones — what ships first and why
- The key technical and product risks, and how the plan de-risks each
- Checkable success criteria

Limit: 800 words.
